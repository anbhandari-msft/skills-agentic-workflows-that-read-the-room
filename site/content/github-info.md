## Awesome Copilot workflow ideas

Source: [Awesome Copilot workflows](https://awesome-copilot.github.com/workflows/)

Awesome Copilot lists ready-made agentic workflow examples you can adapt. Each is a Markdown file with frontmatter (trigger, permissions, safe outputs) plus plain-language instructions:

- **Daily Issues Report**: weekday summary of new, closed, and stale issues, posted as a labeled issue.
- **OSPO reports** (contributors, org health, release compliance, stale repos): open source program office health checks.
- **Relevance check / summary**: assess and summarize whether items are still relevant.
- **Weekly comment sync**: recurring comment synchronization.

Tip: start from the Daily Issues Report pattern (read-only permissions, one safe output) and customize it.
